## 6. Design decisions

- **Deployment = symlinks**, one link per config entry, listed in `config.manifest`. Edits land in git immediately, and drift is easy to see with `git status`. Rollback means removing the link and restoring the timestamped backup. A pre-existing live file is **moved** into `~/.local/state/dot-files/backups/<timestamp>/` and never deleted. A live file that already differs from the repo is never overwritten silently: the installer reports it, backs it up, and only then links.
- **Hyprland Lua layout** (user-specified naming). `hyprland.lua` is the only entry point Hyprland reads, and it loads the following modules in order, each inside `pcall`:

  | File | Contents |
  | --- | --- |
  | `monitors.lua` | Monitor modes / scale (VirtIO, 1920×1080) |
  | `env.lua` | Environment variables, toolkit/Wayland integration |
  | `general.lua` | UI / aesthetic: gaps, borders, decoration, animations, layouts, misc |
  | `input.lua` | Keyboard / pointer / devices |
  | `workspaces.lua` | Workspace rules and window/layer rules |
  | `exec.lua` | Autostart / session processes (WayVNC, wallpaper, polkit, clipboard, island) |
  | `keybinds.lua` | **The single binding registry** (data only) |
  | `custom.lua` | Personal, machine-local tweaks; loaded last |
  | `lib/binder.lua`, `lib/safety.lua` | Registry → `hl.bind` + shortcuts view; rescue binds and module error reporting |
  | `hypridle.conf`, `hyprlock.conf`, `hyprpaper.conf` | Their own hyprlang formats, deployed alongside |

  A broken module produces a notification, and the other modules still apply. `lib/safety.lua` applies a hard-coded rescue bind (`SUPER+Return` → kitty) before anything else.
- **Binding registry:** `keybinds.lua` is pure data. `lib/binder.lua` turns it into `hl.bind` calls and writes `$XDG_RUNTIME_DIR/kessel/shortcuts.txt`, which is shown with `SUPER+/` through fuzzel (Quickshell-independent). `scripts/gen-shortcuts.sh` renders `docs/SHORTCUTS.md` from the same registry using `Hyprland --verify-config`.
- **Fonts:** JetBrainsMono Nerd Font everywhere. Shared sizes are UI 11 and mono 12. Qt/GTK pick them up through fontconfig plus GTK `settings.ini`.

## 7. Changes proposed before touching live config

1. Back up `~/.config/hypr/hyprland.lua` (+ empty `~/.config/kitty/`).
2. Validate the new tree with `--verify-config` in a scratch location.
3. Deploy the Hyprland symlinks; Hyprland auto-reloads. Verify `SUPER+Return` and SSH, and confirm WayVNC is still on `127.0.0.1:5900` (Hyprland does not restart WayVNC on reload).
4. Shell: test fish interactively and over SSH (`ssh kessel fish -c true`) before any `chsh`.
